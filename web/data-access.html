Scientific services

The server package provides THREDDS WMS 1.3.0 map images, WCS 1.0.0 NetCDF coverages and OPeNDAP DAP2 subsets for the January and March Bay of Bengal cases. Both have passed source-value and protocol checks. The Arabian Sea download and REST API are available; its THREDDS route is configured but has not had the same protocol checks.

Public availability: the download and REST API work on this Vercel site. The THREDDS service is configured separately and has no public address in this preview. It requires a persistent server; the browser viewer does not depend on it.

WMS and WCS can slightly regularize the horizontal coordinates. Use the native download or OPeNDAP when exact source coordinates matter.

Publication updates and offline work

Sources in the workspace shows the serving publication, historical coverage and original retrieval dates. Check publication refreshes that status without discarding the current view. New historical case packs are validated and deployed with a compatible app release. This demo has no automatic live-data scheduler.

Saved investigations can download a self-contained Offline viewer for observation profiles, comparisons and native model columns. Values, dates, quality flags and source references travel with the file. No network is needed to inspect those saved values. New analysis still requires the source data and online service.

Definitions and limits

The exchange file declares CF-1.10. It uses positive-down depth in metres and a proleptic Gregorian time axis. Practical salinity uses CF's dimensionless unit 1; its numbers are unchanged from the source psu field. Original units and names remain attached to each field.

These are historical model analyses, not current conditions or operational advisories. HYCOM assimilates observations, so agreement with Argo is not independent forecast validation. Curvilinear and rotated grids, pressure or sigma vertical coordinates, and non-Gregorian calendars need separate adapters.

The extension contract distinguishes derived and externally supplied ML products. No ML prediction is included in this release.
